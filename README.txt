MyClient — Fabric 1.21.4

Сборка: JDK 21 + Gradle 8.12+ -> gradle build -> build/libs/myclient-1.0.0.jar
В папку mods вместе с Fabric API 0.119.2+1.21.4.

Управление:
Right Shift — ClickGUI (ЛКМ вкл/выкл, ПКМ настройки, СКМ смена бинда, Backspace — убрать бинд)
G Sprint | B Fullbright | F Flight | R ESP | V Tracers | T TriggerBot
AutoTool и AutoRespawn без бинда — включаются в ClickGUI.
Конфиг: config/myclient.json (бинды и настройки, сохраняется при закрытии GUI).

Только для одиночной игры и своих серверов.
